## 本轮交付

- 固定左小腿，无镜像。前、后、内侧、外侧、后内侧预设与自由旋转。
- 四个显露状态：全部肌群、隐藏腓肠肌、原位淡化比目鱼肌、深后室重点。
- 单独控制肌群、骨骼、骨间膜、血管与神经；比目鱼肌透明度连续调节。
- 遮挡深度由当前显示的不透明骨骼和肌肉计算。被遮挡神经血管以 18% 强度透视；关闭透视时隐藏。淡化肌肉不参与不透明遮挡计算。
- 横断面由模型三角形与水平面的交线计算。固定从远端向近端看：前在上、后在下、左小腿外侧在画面左。横断面始终保留全部肌群供定位。
- 中英各四张 3840×2160 PNG，位于 `teaching-images/`；页面可导出当前视图。

## 解剖与证据复核记录

这是软件与教学表达辅助复核，不是另一位临床专家独立签审。

1. **左右侧**：所有解剖源条目均指定 left；未施加镜像。坐标转换仅平移和米至毫米换算。保留源坐标方向：+x 为左小腿外侧，+y 为近端，+z 为前方。程序核查腓骨中心位于胫骨中心外侧。临床外观复核仍待教师完成。
2. **深后室显露**：导入胫骨后肌、趾长屈肌、拇长屈肌；与比目鱼肌、腓肠肌及骨间膜保持源坐标关系。隐藏/透明不改变解剖坐标，不是切除、牵拉距离或组织变形模拟。没有假造可直接用于操作的筋膜间隙。
3. **遮挡**：逐像素比较神经血管深度与不透明骨/肌深度，非整根神经统一透明。软件测试记录见 `validation.json`。切换有真实像素差异，不代表路径已获得临床解剖确认。
4. **数据局限**：图谱网格是通用静态标本，局部肌肉/血管可能相交；不能由网格贴合推断实际可分离间隙。所有神经是人工教学中心线，未完成独立路径校验，不能用于判断安全距离。未包含完整分支、腓动脉等所有重要结构；没有全套皮肤、深筋膜、肌间隔或松解动画。
5. **临床依据**：AO 的小腿双切口说明用于解释前外侧与内侧显露，以及比目鱼肌下深后室及胫后神经血管保护。BOASt 2025 支持确诊后及时减压及全部受累室处理。此样版不新增固定切口深度、器械角度或牵拉幅度。操作与参数仍参见已有二维模块。

## 需教师重点反馈

- 后内侧视角是否清楚表达比目鱼肌对深后室的覆盖？
- 黄色神经示意是否应进一步按权威解剖图谱校正后再用于正式授课？
- 18% 的遮挡透视强度是否足够，或希望改为完全隐藏？
