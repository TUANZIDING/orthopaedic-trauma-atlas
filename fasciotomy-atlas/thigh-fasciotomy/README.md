## 阅读图示

左侧为入路与筋膜层展开示意；右侧为关系横断面。紫红虚线为皮肤切口，紫红实线为筋膜松解；红色动脉、蓝色静脉、黄色神经。表面图中不同层被展开，不能按图量取距离或盲切。

前、后、内侧三室分别评估。本图按 AO 的外侧与内侧入路教学，不能将外侧皮切口等同全部三室已减压。

Assess anterior, posterior and medial compartments separately. This AO-based lateral/medial approach map does not equate one lateral skin incision with complete release.
